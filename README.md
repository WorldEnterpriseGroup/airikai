## Website

- AI Solutions Portfolio
- Blog & Resources
- Certifications & Training
- Events & Webinars
- Media Gallery
- Course Offerings

## Technology Stack

- HTML5/CSS3
- JavaScript
- Responsive Design
- GitHub Pages Hosting

## Getting Started

To run this website locally:

1. Clone this repository
2. Open `index.html` in your web browser
3. Navigate through the site using the provided navigation
